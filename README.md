# Alae Ddine El Jirari

### Data Engineer · Azure · Spark · Kafka · Airflow

I build data pipelines that turn raw operational data into warehouses people can actually query: ingestion, cleaning, dimensional modeling, orchestration and the CI/CD around it.

My background is a Master's in Big Data & Cloud Computing, and I back it with projects that run end to end, from the source database to the star schema.

**Open to Data Engineer roles** (full-time, remote or on-site).

---

## What I do

- **Data warehousing**: star schema design, fact and dimension tables, ELT into Azure Synapse dedicated and serverless SQL pools
- **Batch and streaming**: Apache Spark and Spark SQL for batch, Apache Kafka and Kafka Streams for real-time
- **Orchestration**: Apache Airflow DAGs with SQL tasks, sensors and data checks that alert on failure
- **Data quality**: cleaning messy sources (mixed date formats, duplicates, missing values) into reliable tables
- **MLOps and CI/CD**: data and model versioning with DVC, automated training reports with GitHub Actions and CML
- **Backend**: Java / Spring Boot and Python / FastAPI services on top of PostgreSQL

## How I work

- I model the data before I write the pipeline, so the warehouse answers the business questions it was built for.
- I treat data quality as part of the pipeline, with checks that fail loudly instead of loading bad rows.
- I document what I build, so the next engineer can run it without asking me.
